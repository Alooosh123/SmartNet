# نتائج مراجعة main

- README يصف React frontend وبوت Telegram، لكن شجرة main التي تمت مراجعتها لا تحتوي `frontend/src/App.jsx` ولا `backend/bot/main_bot.py`.
- قاعدة البيانات الافتراضية SQLite.
- إعدادات JWT وWebhook وبيانات admin لها قيم افتراضية في settings.py ويجب استبدالها خارج Git قبل الإنتاج.
- subscription_agent.py يعتبر صورة الإيصال كافية لتعيين paid وإنشاء/تفعيل Client؛ هذا غير كافٍ لإثبات وصول المال.
- mikrotik_api.py يعود في بعض حالات فشل الاتصال إلى بيانات Demo؛ يجب ألا تُعرض كبيانات حقيقية.
- المستودع يتتبع ملفات __pycache__ وملف قاعدة بيانات ومخرجات PDF وuploads.
- بعض الاختبارات تتضمن فصل مستخدم وإعادة تشغيل الراوتر؛ لا تشغّلها على راوتر الإنتاج.

هذه نتائج قراءة ملفات main فقط، وليست نتيجة تشغيل الاختبارات أو الوصول إلى راوتر حقيقي.
