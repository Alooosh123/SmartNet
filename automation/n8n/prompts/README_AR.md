# تعليمات وكلاء SmartNet

هذه الملفات مخصصة لحقل System Message في عقد AI Agent داخل n8n. لا تفعل أي Workflow قبل إضافة نموذج محادثة محلي أو سحابي معتمد، وضبط مصادقة Webhook. ابدأ بأدوات القراءة فقط، واجعل عمليات الشبكة والمدفوعات والنسخ والاستعادة والنشر خلف موافقات Backend موثقة. لم يتم ربط هذه التعليمات بنموذج أو عقد AI Agent بعد.
