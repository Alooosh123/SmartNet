# مصفوفة أدوات وصلاحيات وكلاء SmartNet

## القاعدة العامة

كل Workflow متصل بعقدة AI Agent 3.1 وعقدة OpenAI Chat Model 1.2 باستخدام `gpt-6-luna`. النموذج مستشار مساعد فقط، ولا توجد AI Tools أو صلاحيات تنفيذ موصولة به. نتيجة Code node الحتمية هي القرار التشغيلي؛ نص النموذج يظهر منفصلاً في `ai_advisory`.

| الوكيل | نطاق التحليل المسموح للنموذج | المحظور |
|---|---|---|
| 00 Supervisor | تصنيف المهمة واقتراح المسار من القائمة الثابتة | تنفيذ أو استدعاء غير مصرح به، وعمليات الشبكة والمال والنشر |
| 01 Repository | تفسير جرد شجرة GitHub العامة | تعديل المستودع أو Push |
| 02 Security | تفسير أسماء ومسارات ملفات | كشف أسرار أو استغلال أو ادعاء فحص محتوى لم يحدث |
| 03 RBAC | مراجعة أدوار وصلاحيات مسموح بها | منح صلاحية أو تعديلها |
| 04 Database | تقييم علامات النسخ والترحيل والاستعادة | حذف أو استعادة أو ترحيل إنتاجي |
| 05 MikroTik Gate | تقييم متطلبات بيئة اختبار معزولة | الاتصال بالراوتر أو إصدار أوامر RouterOS |
| 06 Monitoring | تفسير نتيجة GET /api/health | فصل مستخدم أو تعديل واجهة؛ لا يدعي سلامة DB أو الراوتر |
| 07 Diagnosis | ترتيب فرضيات من مقاييس رقمية إجمالية | أوامر RouterOS أو تمرير معرفات/ملاحظات مشتركين |
| 08 Payment | تفسير اكتمال الحقول | اعتماد الدفع أو تفعيل الاشتراك أو تغيير الرصيد |
| 09 Reconciliation | تفسير رموز اختلاف بعد المقارنة في Backend | تعديل Ledger أو سجلات الدفع |
| 10 Approval | شرح متطلبات موافقة بشرية على إجراء | تنفيذ الإجراء أو اعتبار الطلب تفويضاً |
| 11 QA | تفسير فحص صحة آمن | اختبارات متغيرة على الإنتاج أو ادعاء تشغيل حزمة كاملة |
| 12 Release | تفسير أدلة go/no-go | النشر أو DNS أو Restart |

## تقليل البيانات قبل n8n

- 01 و02 و06 و11 يستقبلون معرف الطلب فقط.
- 07 يستقبل cpu_load_pct وmemory_free_pct وactive_users_delta فقط.
- 08 لا يستقبل رقم الحوالة أو المبلغ أو العملة أو اسم المحفظة؛ يستقبل علامات وجود الحقول وأسماء الحقول الناقصة.
- 09 يجري مقارنة المرجع والمبلغ والعملة والمستفيد داخل Backend في الذاكرة، ثم يرسل رموز اختلاف وعلامات وجود دون القيم.
- 10 لا يستقبل نص الهدف أو سبب طلب الموافقة.
- 03 لا يستقبل إلا أسماء أدوار وصلاحيات من قائمة سماح.
- 04 و05 و12 لا تستقبل إلا أسماء محركات محددة وعلامات checklist منطقية.
- 00 يستقبل اسم المهمة ومعرف الطلب فقط.

## جسر Backend

المسارات `/api/v1/automation/*` إدارية وتتطلب صلاحية مدير. لا يقبل الجسر URL من المستدعي؛ يختار المسارات من قائمة ثابتة، ويُسجل المعرف والوكيل والحالة دون حفظ Payload. التكامل معطّل افتراضياً إلى أن تُضبط `N8N_ENABLED` و`N8N_BASE_URL` وHeader Auth في البيئة المحلية.

## حواجز Backend الإلزامية

- تحقق من هوية خدمة الأتمتة عبر اعتماد مستقل محدود.
- استخدم قائمة سماح للأفعال والمسارات؛ لا تقبل URL أو أمر نظام يقدمه النموذج.
- عمليات الكتابة تحتاج idempotency key وسجل تدقيق.
- الموافقة البشرية محددة النطاق والمدة والصلاحية وتُستهلك مرة واحدة.
- لا تمنح n8n وصولاً مباشراً إلى بيانات العملاء الحساسة أو مفاتيح الراوتر أو سجلات الرصيد.
- لا تحفظ الإيصالات أو كلمات المرور أو بيانات الدفع في ذاكرة النموذج أو سجلاته.
- أي إضافة مستقبلية لأداة كتابة تتطلب Backend gate منفصلاً واختبارات رفض ومراجعة مستقلة؛ لا توصلها مباشرة إلى AI Agent.
