# مصفوفة أدوات وصلاحيات وكلاء SmartNet

| الوكيل | الأدوات والمصادر المسموحة | المحظور |
|---|---|---|
| 00 Supervisor | سجل الوكلاء وحالة المهام واستدعاء Workflow آمن | عمليات الشبكة والمال والنشر |
| 01 Repository | GitHub للقراءة وشجرة الملفات وCI | تعديل المستودع أو Push |
| 02 Security | pip-audit وBandit وGitleaks وقراءة الإعدادات | كشف الأسرار أو الاستغلال |
| 03 RBAC | تعريفات الأدوار والمسارات والاختبارات | منح الصلاحيات أو تعديلها |
| 04 Database | migrations وتقارير النسخ والاستعادة | حذف أو استعادة إنتاجية |
| 05 MikroTik Gate | إعدادات الاختبار ونتائج القراءة | أوامر RouterOS المتغيرة |
| 06 Monitoring | health وNetwork Observer metrics | فصل مستخدم أو تعديل واجهة |
| 07 Diagnosis | قاعدة المعرفة وقياسات القراءة | تنفيذ أوامر الراوتر |
| 08 Payment | بيانات Adapter موثوق | اعتماد أو تفعيل أو تغيير رصيد |
| 09 Reconciliation | كشف CSV والسجلات للقراءة | تعديل دفتر الأستاذ |
| 10 Approval | إنشاء وعرض طلب موافقة | تنفيذ الإجراء |
| 11 QA | CI وpytest وPlaywright وAndroid build | اختبارات متغيرة على الإنتاج |
| 12 Release | تقارير CI والإعدادات وخطة الرجوع | نشر أو DNS أو Restart |

## حواجز Backend الإلزامية
- تحقق من هوية خدمة الأتمتة عبر اعتماد مستقل محدود.
- استخدم قائمة سماح للأفعال والمسارات؛ لا تقبل URL أو أمر نظام يقدمه النموذج.
- عمليات الكتابة تحتاج idempotency key وسجل تدقيق.
- الموافقة البشرية محددة النطاق والمدة والصلاحية وتُستهلك مرة واحدة.
- لا تمنح n8n وصولاً مباشراً إلى بيانات العملاء الحساسة أو مفاتيح الراوتر أو سجلات الرصيد.
- لا تحفظ الإيصالات أو كلمات المرور أو بيانات الدفع في ذاكرة النموذج أو سجلاته.
