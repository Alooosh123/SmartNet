# دليل توصيل System Prompts مع n8n المحلي

## الحالة الحالية
- ملفات Workflows الحالية هي حواجز وفحوص آمنة تعمل بعقد Webhook/Code/Response.
- يوجد Prompt مستقل لكل وكيل داخل `automation/n8n/prompts/`.
- لم تتم إضافة عقد AI Agent أو Chat Model إلى ملفات JSON بعد.
- إصدار n8n المحلي والعقد المثبتة وبيانات اعتماد النموذج غير متاحة للفحص عن بُعد؛ لذلك لم يتم تخمين مخطط عقدة قد يفشل عند الاستيراد.

## خطوات الربط المحلي
1. استورد Workflows واتركها غير مفعّلة.
2. أضف AI Agent node في Workflow فرعي للوكيل المطلوب.
3. اختر Chat Model المدعوم في نسختك، واضبط بيانات الاعتماد داخل n8n Credentials.
4. انسخ System Prompt المطابق من مجلد prompts إلى System Message.
5. مرر بيانات الطلب كمدخل منفصل عن System Message.
6. ابدأ بأدوات القراءة فقط، ثم أضف عقدة تحقق من JSON والصلاحيات.
7. لا توصل قاعدة البيانات أو الراوتر أو إجراءات الدفع إلى أداة عامة تنفذ أوامر.
8. اختبر إدخالاً عادياً، ومدخلاً ناقصاً، ومحاولة توجيه الوكيل لتجاوز دوره قبل التفعيل.

## ترتيب الربط
- أولاً 01 و02 لفحص المستودع والأمان.
- ثم 07 للتشخيص مع قاعدة المعرفة ومقاييس القراءة فقط.
- ثم 00 للتنسيق بعد نجاح الوكلاء الفرعية.
- 08 و09 و10 تبقى تحققاً ومطابقة وموافقات؛ لا تعطها أدوات مالية متغيرة.

## شرط قبول
يجب أن ينتج كل وكيل JSON صالحاً. عند فشل التحليل أو التحقق من المخطط، أوقف المسار ولا تستدعِ أي أداة ذات أثر جانبي.
